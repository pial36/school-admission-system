# School Admission System

First-come-first-served online admission system for a school.
Parents apply for a seat in a class (each class + shift is its own "class"),
the seat is **held** for a limited time, and paying the admission fee **confirms** it.

**Stack:** .NET 8 · PostgreSQL · React 18 (Vite) · Docker

## Repository layout

```
backend/    ASP.NET Core 8 Web API + tests
frontend/   React 18 + Vite UI
docker-compose.yml
```
